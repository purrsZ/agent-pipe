商品收藏

你在「快拍 · 定方向」
快拍看大纲定方向 + 拍接口合同
慢拍各端详设逐条挑刺

一句话背景

用户想把喜欢的商品收起来，下次直接找到。

改完啥样

商品页多个收藏按钮，点了进「我的收藏」；列表里能取消。

范围

做收藏 / 取消 / 收藏列表（分页、按时间倒序）
不做收藏夹分组、降价提醒（留后续需求）

怎么拆（4 个工人并行）

用户服务 存收藏关系 + 列表接口商品服务 批量取商品信息Web 按钮 + 列表页App 按钮 + 列表页

关键取舍（3 条，最该你看）

  1. 收藏关系存「用户服务」，不存商品服务——按"谁拥有这份数据"划。
  2. 列表里的商品名/图实时从商品服务取，不冗余存——怕商品改名/下架后对不上。
  3. 收藏上限 1000，后端硬兜底，前端先拦提示。

已知的坑

① 收藏的商品下架了，列表怎么显示。② 批量取商品信息的性能。（详览与质疑里展开）
